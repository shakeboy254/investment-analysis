# 投资技术与收益分析

> 个人投资方法论与收益归因分析记录。仅用于研究与复盘，**不构成投资建议**，不承诺任何收益。

## 内容结构

| 目录 | 内容 |
|---|---|
| `docs/` | 方法论沉淀：估值三锚定+一底线、高股息三看+一排除、TTM 股息率口径、价值陷阱红线、缩量双确认 |
| `scripts/` | 数据抓取、指标计算、回测与收益归因脚本（脱敏模板） |
| `reports/` | 报告模板与样例（**不含真实持仓与成本**） |

## 数据与隐私

本仓库为 **Public**，因此明确排除以下内容，相关文件已写入 `.gitignore`：

- 真实持仓、成本价、股数、账户资金（`sim_account.json`、`watch_guoci.json`）
- 候选池与自选池导出（`watch_pool_*.json`）
- 本地行情数据库（`*.sqlite` / `*.db`）
- 任何密钥、Token、`.env`

## 使用边界

- 所有结论标注「参考执行区间」，非绝对买卖指令。
- 事实（财报/行情/政策原文）与判断（估值修复、产业落点）严格分开。
- 历史分红、历史收益不代表未来表现。
