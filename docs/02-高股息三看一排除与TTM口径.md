# 02 · 高股息三看一排除 + TTM 口径

> 用途：判断高股息是「真金白银」还是「吃老本」。核心结论：**不用 TTM 口径算，会系统性低估派息率，把陷阱看成机会。**

## 三看

| 看什么 | 门槛 | 说明 |
|---|---|---|
| **看现金流覆盖** | 每股经营现金流净额 ÷ 每股股息 **≥ 1.5**；严格版：`FCF ÷ 分红总额 ≥ 1.2`（FCF = CFO − 资本开支） | 证明分红来自经营，不是借债或卖资产 |
| **看分红率** | **30%–70%** 为健康区 | > 80% 警惕；> 100% 直接淘汰 |
| **看盈利稳定** | 扣非不连续下滑，非周期顶部 | 周期顶部的分红不可外推 |

## 一排除（三类伪高股息，命中即剔除）

1. **一次性分红**：处置资产、重组、特别股息等非经常性来源。
2. **周期顶部高分红**：煤炭/钢铁/航运/化工等强周期峰值期的假高股息。
3. **高杠杆分红**：有息负债高企仍高比例分红。

## TTM 口径（本文档的核心）

### 为什么必须用 TTM

只用「最近一个完整年度」会**漏计已宣告但尚未除权的当年中期分红**，导致派息率被系统性低估。

### 三个公式

```
TTM 每股派息 = 上一年度分红 + 本年度中期分红（元/股）

TTM 扣非净利 = 上年全年扣非 − 上年 H1 扣非 + 本年 H1 扣非

TTM 股息率 = TTM 每股派息 ÷ 现价
TTM 派息率 = TTM 每股派息 × 总股本 ÷ TTM 扣非净利
```

### 计入规则（关键）

中期分红按 `ASSIGN_PROGRESS ∈ {董事会决议通过, 股东大会决议通过, 实施分配}` 计入，**不看 `EX_DIVIDEND_DATE` 是否已到**。

如果按「过去 12 个月已实施派息（以除权除息日归属）」计算，就会漏掉「已通过但未除权」的中期分红。

### 实证：同一家公司，两个口径差 4 倍

> **健康元 600380**（数据截至 2026-10）
>
> - 旧口径（只算已实施）：股息率 2.38%，派息率 30.1%，看起来「股息率不足」。
> - TTM 口径：2025 年度 10 派 2.2 + 2026 中期 10 派 7.1 = 0.93 元/股 × 18.29 亿股 ≈ 17.01 亿；TTM 扣非 = 13.07 − 7.70 + 6.04 = 11.41 亿。
> - 结果：**TTM 股息率 10.04%，TTM 派息率 149.1%** —— 直接触发价值陷阱一票否决。
>
> 同一家公司，旧口径看不出问题，TTM 口径一眼是陷阱。

### 正例：口径修正后质量上修

> **新乳业 002946**：TTM 口径下股息率由 2.63% 修正为 **3.19%**（达到门槛），派息率 47.3%，仍在健康区。这类是「口径修正后变得更好」，与上文的「修正后变陷阱」方向相反，都要按 TTM 重算。

## 数据源与单位

| 数据 | 来源 | 单位处理 |
|---|---|---|
| 分红明细 | 东财 `RPT_SHAREBONUS_DET` | `PRETAX_BONUS_RMB` 为元/10 股，**÷10** 得元/股 |
| 中期分红 | 同上，`REPORT_DATE = 本年 06-30` | 含「董事会决议通过」状态即可计入 |
| 扣非净利 | 利润表 / 东财财务接口 | 统一亿元 |

## 红利税（报告必须标注税后口径）

| 持股期限 | 税率 |
|---|---|
| ≤ 1 个月 | 20% |
| 1 个月 – 1 年 | 10% |
| > 1 年 | 免征 |

默认按持有 1 年以上免税列示，同时注明其他档位。

## 检查清单

```
[ ] 已用 TTM 口径，不是「最近一个完整年度」？
[ ] 中期分红是否已计入（哪怕尚未除权）？
[ ] TTM 扣非是否按「上年全年 − 上年H1 + 本年H1」滚动？
[ ] 股息率 ≥ 3%？（≥4% 优先）
[ ] 派息率在 30%–70%？
[ ] FCF 覆盖 ≥ 1.2（或每股 CFO/股息 ≥ 1.5）？
[ ] 是否命中三类伪高股息？
[ ] 是否触发价值陷阱红线（派息/扣非 > 100%）？
```
