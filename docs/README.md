```

```

## 三条总纪律

1. **阈值就是阈值**：不因选不满而放松，不取近似值。
2. **事实与判断分离**：财报/行情/政策原文是事实；产业落点、估值修复、赔率是判断，不得写成事实。
3. **结论必须可证伪**：每个看多/看空判断都挂一个未来验证节点，否则不算结论。
