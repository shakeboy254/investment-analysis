# 05 · 中长线埋伏纪律

> 定位：6–12 个月（中长线档）为主、1–2 年（长线档）为辅。**不做 T、不做小波段，年换手 < 100%**，只做牛熊级仓位管理（年 ≤ 2 次）。

## 一、五层漏斗（逐层一票否决）

| 层 | 内容 | 关键阈值 |
|---|---|---|
| ① 排雷 | ST/*ST、退市风险、连续亏损、立案调查、审计非标、商誉/净资产 > 30% 且持续减值、质押 > 60%、次新解禁密集 | 任一命中即淘汰 |
| ② 行业 | 剔除政策出清、需求永久萎缩、技术被颠覆的赛道 | 只选「景气底部但逻辑未破坏」 |
| ③ 基本面 | 三锚定 + 一底线（见文档 01） | 十项全过 |
| ④ 估值 | PE/PB 近 10 年分位 < 30%，股息率 ≥ 3% 兜底 | 说清「股价已包含什么预期」 |
| ⑤ 技术 | 底部 6 信号至少满足 3 项，**长期缩量为必选** | 见下 |

## 二、底部 6 信号

1. **长期缩量（必选）**：周缩量前 5 周 + 前 12 周双确认 ≤ 0.6，且换手率 < 3%。
2. **长期横盘**：箱体震荡，不再创新低。
3. **均线粘合**：5/10/20/60 日线缠绕收敛。
4. **MACD 底背离**：股价新低，MACD 不新低。
5. **破净/低位**：PB 历史低位或接近破净。
6. **放量突破 + 缩量回踩**：突破放量 1.5–2 倍，回踩缩量不破位（右侧加分项）。

**破位过滤**：收盘 < MA20 × 0.97 的标的剔除（介入过滤，不是持仓止损）。

## 三、仓位与建仓

| 项目 | 规则 |
|---|---|
| 总仓位上限 | 震荡/熊市基准 50%；牛市 60%；强牛 70% |
| 现金安全垫 | 全程 ≥ 30% |
| 单票上限 | 20%–30% |
| 建仓节奏 | 分 3–5 批，金字塔；首仓 ≤ 1/3；每跌 10% 加一批 |
| 卖出节奏 | 主升浪每涨 15%–20% 卖出 1/4（越涨越卖） |

## 四、止损：三层兜底（长线不设单点止损）

### 第一层：基本面证伪（任一触发 → 无条件离场，禁止越跌越买）

- 业绩变脸：单季归母净利同比转负，或扣非连续 2 季同比下滑 > 30%
- 现金流断裂：经营现金流连续 2 季为负
- 负债恶化：有息负债率单季跳升 > 10 个百分点
- 分红中断：削减或停发股息
- 减值暴雷：单季大额商誉/资产减值
- 审计非标

### 第二层：总回撤熔断

组合自峰值回撤 > 30% → 暂停一切加仓，全面复核基本面。

### 第三层：技术兜底

月线收盘跌破 MA60 / MA120 → 长期趋势终结，减仓。

> MA20 × 0.97 只作**介入过滤**，不作长线持仓止损。

## 五、右侧三共振（长线介入信号）

三条同时成立才介入：

```
① 月线 MA60 拐头向上（本月 > 上月，连续 2 月）
② 周线放量突破 20 周箱体（周收盘 > 前 20 周最高价，且周量比 ≥ 1.5）
③ 扣非归母连续 2 个季度同比改善
```

## 六、短线三共振（对照，不用于长线）

```
① 当日收盘价 > 前 20 日最高收盘价
② 量比（对 20 日均量）≥ 1.5
③ 周 MACD 金叉（DIF 上穿 DEA）
```

三者缺一不介入；其中「价格突破 20 日新高」不可被补位。

## 七、执行前自检

```
[ ] 五层漏斗是否逐层过？
[ ] 长期缩量是否双确认？
[ ] 是否仍在新低？（新低不接）
[ ] 单票仓位、总仓位、现金比例是否合规？
[ ] 基本面证伪条件是否写明？
[ ] 是否有可证伪的未来验证节点？
[ ] 介入价/止损/目标是否标为「参考执行区间」？
```

## 八、纪律红线

- 不追高：BIAS20 > +8% 只限回踩。
- 不摊平亏损：基本面证伪后禁止越跌越买。
- 不因「跌得多」建仓：跌幅不是估值。
- 不因「选不满」放宽阈值：0 只是正常结果。
