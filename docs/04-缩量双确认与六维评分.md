# 04 · 缩量双确认与六维评分

> 用途：底部不是「跌得多」，而是「跌不动 + 量能枯竭 + 不再创新低」。缩量是前置闸门，评分是排序工具。

## 一、缩量三口径（阈值一律 ≤ 0.6，即收缩 ≥ 40%，不得放宽）

### 周缩量（主口径，双确认）

```
本周成交量 ÷ 前 5 周均量  ≤ 0.6
且
本周成交量 ÷ 前 12 周均量 ≤ 0.6
```

- 前 5 周：捕捉「近期突然缩量」的拐点。
- 前 12 周：确认「量能处于中期低位」，过滤早期放量干扰。
- 两值同时达标才算周缩量，单看一个容易被单周噪声骗过。

### 日缩量（辅助，择时用）

```
当日成交量 ÷ 近 60 日均量 ≤ 0.6
且
近 5 日均量 ÷ 近 60 日均量 ≤ 0.6
```

### 地量硬门槛

```
换手率 < 3%
```

### 呈现优先级

```
周口径 > 5 日口径 > 日口径
```

中长线选股以周口径为主判据；日口径只用于寻找介入点。

## 二、三个数据口径坑

| 坑 | 表现 | 修正 |
|---|---|---|
| **周中未走完的周量** | 周五前统计「本周量」，天然偏低，误判缩量 | 只取**最近一个完整交易周** |
| **盘中折算量** | 盘中缩量会因「全天/盘中 ≈ 2.3–3.2 倍」系统性虚高 | 一律用收盘真实成交量 |
| **单位不统一** | 腾讯 `vol` 单位是「手」，新浪 K 线是「股」 | 腾讯 ×100 后再比较 |

补充：新浪日 K 可能滞后 1 个交易日，盘中任务改用东财 `push2his`（含当日 bar）。

## 三、六维评分（100 分制）

| 维度 | 权重 | 看什么 |
|---|---|---|
| 趋势 | 30 | 均线排列、周线/月线方向、是否站稳 MA20/MA60 |
| 逢低 | 20 | 回踩位置、BIAS 偏离度、是否追高 |
| 量能 | 15 | 缩量双确认、地量、放量突破质量 |
| 形态 | 15 | 箱体、均线粘合、底背离、突破/回踩结构 |
| 动量 | 10 | 短期涨跌节奏、MACD/RSI |
| 风险 | 10 | 破位、解禁、质押、商誉、审计 |

### 评级映射

| 分数 | 含义 | 动作 |
|---|---|---|
| ≥ 90 | 强候选（= 10 分制 9/10） | 优先入选 |
| 80–89 | 入选 | 可建仓/观察 |
| 60–79 | 观察 | 不建仓，等信号 |
| < 60 | 淘汰 | — |

## 四、必须同时成立的组合条件

缩量只是「必要」，不是「充分」。中长线底部至少要同时满足：

```
低估值（PE/PB 分位 < 30%）
+ 高股息（TTM 股息率 ≥ 3%，派息率 30%–70%）
+ 缩量双确认（周 ≤0.6 且 ≤0.6）+ 换手率 < 3%
+ 基本面三锚定一底线全过
+ 不再创新低
```

缺任何一项都不算「底部埋伏」，只能算「跌了很多」。

## 五、常见误判

| 误判 | 真相 |
|---|---|
| 缩量 = 有人控盘 | 缩量只说明分歧减少，可能继续阴跌 |
| 跌 50% = 到底 | 跌幅不是估值，先看基本面是否恶化 |
| 单日地量 = 启动 | 需周口径双确认 + 价格不再新低 |
| 评分高 = 可以买 | 评分是排序，不是买入许可；先过缩量与基本面闸门 |
