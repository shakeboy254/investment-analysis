# 01 · 估值三锚定 + 一底线

> 用途：判断一只票是「真便宜」还是「假便宜」。这是介入前的第一道闸门，不过不碰。

## 一句话

**盈利能持续、现金流能兑现、资产不虚胖，再加一条审计与商誉的底线。** 四项任一不过，直接淘汰。

## 三锚定

| 锚 | 量化门槛 | 数据来源 | 一票否决 |
|---|---|---|---|
| **盈利锚** | 连续 3 年扣非净利为正；最近 4 季滚动归母净利 > 0；ROE 长期 ≥ 8% | 年报/季报 `扣非净利润`、`ROE` | 是 |
| **现金流锚** | 近 3 年经营现金流净额均为正；`CFO ÷ 归母净利 ≥ 0.8`（最好 ≥1） | 现金流量表 | 是 |
| **资产锚** | 有息负债率 ≤ 50%（资产负债率 ≤ 60%，金融/地产除外）；货币资金 + 交易性金融资产 ≥ 短期有息负债 | 资产负债表 | 是 |
| **一底线** | 审计意见标准无保留；商誉 ÷ 净资产 ≤ 30%；无重大资产减值前科 | 审计报告、商誉附注 | 是 |

## 三个必须警惕的「假通过」

### 1. CFO/净利 异常高（> 2）要反向怀疑

现金流远超净利，不一定代表质地好，先查是不是**一次性大额预收/授权首付款**。

> 案例：石药创新 300765，2026H1 扣非 12.26 亿、CFO 27.76 亿（净现比 2.26）。拆开看是阿斯利康 4.2 亿美元 BD 首付款（70% 确认收入）一次性到账。回看年度扣非：2023 +7.44 亿 / 2024 +0.42 亿 / 2025 **−2.94 亿**，盈利锚根本不过。
>
> 结论：凡创新药 / CXO 出现利润或现金流跳变，必须先查「BD 授权收入占比」。

### 2. 周期顶部低 PE 是卖点，不是买点

煤炭、钢铁、有色、石油石化、基础化工、房地产、建材、航运这类强周期行业，盈利顶部会把 PE 压到极低。

- 判据：**以 PB 分位为主、PE 分位为辅**。
- 行业均值一律用**中位数**，不用算术平均（会被极端值带偏）。

### 3. 资产锚要看「有息」不是「全部」

资产负债率里包含大量经营性占款（应付账款、预收款），不产生利息压力。真正压垮公司的是**有息负债**。金融、地产必须按行业口径单独判断，不能套用 50%。

## 执行清单

```
[ ] 连续 3 年扣非净利为正？
[ ] 最近 4 季滚动归母净利 > 0？
[ ] ROE 长期 ≥ 8%？
[ ] 近 3 年 CFO 均为正？
[ ] CFO / 归母净利 ≥ 0.8？
[ ] 有息负债率 ≤ 50%？
[ ] 货币资金 + 交易性金融资产 ≥ 短期有息负债？
[ ] 审计标准无保留？
[ ] 商誉 / 净资产 ≤ 30%？
[ ] 近 3 年无重大减值？
```

十项全过才进入估值与分红环节。任何一项数据缺失，按**不通过**处理，不得用估计值顶替。

## 常见误用

| 误用 | 后果 | 修正 |
|---|---|---|
| 用 PE 低直接判定便宜 | 周期顶部接飞刀 | 周期股改看 PB 分位 |
| 用净利增长代替现金流 | 应收账款堆出来的利润 | 加查 CFO/净利 |
| 用资产负债率一刀切 | 误杀高预收的优质公司 | 改看有息负债率 |
| 用单年数据判断稳定性 | 被一次性收益骗过 | 至少看 3 年 |
