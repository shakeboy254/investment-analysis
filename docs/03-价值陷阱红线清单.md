# 03 · 价值陷阱红线清单

> 用途：把「高股息」里最危险的一类提前拉黑。核心判据只有一条：**派息 / 扣非 > 100%**。

## 判定逻辑

```
TTM 派息率 = TTM 每股派息 × 总股本 ÷ TTM 扣非净利

> 100%  → 一票否决，禁止以「高股息」理由建仓
70%–100% → 黄灯，必须区分「吃老本型」与「现金流支撑型」
30%–70%  → 健康区
```

**为什么 >100% 必然出问题**：分红总额超过当期真实经营利润，缺口只能来自借债、处置资产或历史留存。一旦现金流撑不住，削减分红 → 股息率回落 + 股价下杀，形成双杀。

## 黄灯区（70%–100%）：必须再分两类

| 类型 | 特征 | 处理 |
|---|---|---|
| **吃老本型** | 扣非下滑 + CFO/净利 < 1.2 | 按红线处理，不建仓 |
| **现金流支撑型** | 扣非递增 + CFO/净利 ≥ 1.2 + 有息负债低 | 不等于陷阱，但仍**不得称为「高股息安全」** |

黄灯示例（截至 2026-10）：安图生物 75%、青岛啤酒 77.6%、健帆生物 81%、承德露露 85.7%。

> 青岛啤酒需注意口径：2026 年中期「不分配」是正常中期方案，2025 年度 10 派 23.5 已于 2026-07-16 除权，**不要误判为停止派息**。

## 演化案例：从「超额派息」到「停止派息」

东方雨虹 002271 是一条完整的陷阱演化链：

1. **2025 年**：扣非仅 2.36 亿，派息约 22.6 亿，派息/扣非 ≈ 954%。
2. **当时判断**：超额派息，现金流无法持续。
3. **2026 年**：近 12 个月零派息，2025 年度未分红，股息率归零；2026H1 CFO −3.40 亿。
4. **验证结果**：判断成立——不是「高股息机会」，是「分红不可持续」。

**教训**：高股息策略的第一性问题不是「股息率够不够高」，而是「这个分红明年还在不在」。

## 使用规则

```
[ ] 先算 TTM 派息率，不看单年
[ ] > 100% → 直接拉黑，不得用「低估值 + 拐点」绕过高股息逻辑
[ ] 70%–100% → 查扣非趋势 + CFO/净利，区分吃老本/现金流支撑
[ ] 周期股 → 查近 3–5 年派息是否逐年下降
[ ] 连续派息 < 3 年 → 不纳入高股息池
[ ] 报告中必须标注税后股息率
```
